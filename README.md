# Keyframe feedback

[Keyframe](https://www.keyframe.world) is an animation studio that runs in your browser. This repository is where you report problems and suggest features. The editor's source code is not public.

- **Found a bug?** [Open a bug report](https://github.com/Golden-Chinchilla/keyframe-feedback/issues/new?template=bug.yml).
- **Want something added or changed?** [Suggest a feature](https://github.com/Golden-Chinchilla/keyframe-feedback/issues/new?template=feature.yml).
- **Have a question or want to share what you made?** Use [Discussions](https://github.com/Golden-Chinchilla/keyframe-feedback/discussions).
- **Something private** (your account, billing, a refund): email the address on [our site](https://www.keyframe.world) instead of posting here.

Before you post, search the [open issues](https://github.com/Golden-Chinchilla/keyframe-feedback/issues) — someone may have reported it already. A 👍 on an existing issue helps us see what matters most.

Everything you post here is public. Don't include passwords, payment details or artwork you don't want others to see.

## 中文

[Keyframe](https://www.keyframe.world/zh-CN) 是一个运行在浏览器里的动画工作室。这个仓库用来报告问题和提出功能建议，编辑器的源代码不公开。

- **遇到问题**：[提交问题报告](https://github.com/Golden-Chinchilla/keyframe-feedback/issues/new?template=bug.yml)。
- **想加或改一个功能**：[提交功能建议](https://github.com/Golden-Chinchilla/keyframe-feedback/issues/new?template=feature.yml)。
- **有疑问，或想分享你做的作品**：去 [Discussions](https://github.com/Golden-Chinchilla/keyframe-feedback/discussions)。
- **私人事务**（账户、扣费、退款）：请发邮件到[网站](https://www.keyframe.world/zh-CN)上写的地址，不要发在这里。

发帖前先搜一下[已有的问题](https://github.com/Golden-Chinchilla/keyframe-feedback/issues)，也许已经有人报告过；在已有的问题上点 👍 能帮我们看出大家最在意什么。

这里发的内容都是公开的，请不要附上密码、付款信息或不想公开的画作。
